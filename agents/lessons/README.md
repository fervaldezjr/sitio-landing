# Lecciones

Bandeja del bucle de aprendizaje. Nada de aquí es todavía un estándar.

```
sesión → lessons/inbox/*.md
una persona aprueba → standards/, known-cases/ o el script de verificación
```

## Reglas

- Una lección por fichero, con `_PLANTILLA.md`.
- Sin secretos, correos ni datos personales.
- Lo que debe cumplirse siempre acaba en `scripts/verify.sh`, no solo en un párrafo.
- El siguiente agente lee `inbox/` al empezar, aunque aún no esté aprobada.
