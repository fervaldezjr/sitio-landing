# Casos conocidos

Vacío a propósito. Un caso conocido describe un fallo que volverá en un entorno (logs, colas, producción). Esta landing no tiene entorno de ejecución más allá de GitHub Pages.

Si aparece un fallo repetible del build o del despliegue, se documenta aquí con la firma (mensaje de error) y la comprobación en `scripts/verify.sh`.
